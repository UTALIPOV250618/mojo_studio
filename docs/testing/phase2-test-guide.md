# Той Студия — как проверить фазу 2 (импорт, анализ, моменты)

Что готово: экран «Проекты», создание проекта с загрузкой файлов, анализ видео без распознавания речи (копия для анализа, звук, метрики кадра, смены сцен, плохие кадры, синхронизация камер), остановка и продолжение анализа, уведомление, прогресс на панели задач.

Фаза 2б добавила поиск речи и звуковых событий (этап 2) и моментов по звуку (этап 5): тосты, танцы, аплодисменты, музыка, выход молодых, а во время анализа — лента «Уже найдено».

Чего ещё нет: распознавание текста (фаза 2в), поэтому нет моментов «Подарки» и баллов за ключевые слова; задание, редактор, экспорт.

## 1. Установка (Windows, PowerShell)

Нужны Python 3.12, Git и ffmpeg 7 или новее. Если их нет:

```powershell
winget install -e --id Python.Python.3.12; winget install -e --id Git.Git; winget install -e --id Gyan.FFmpeg
```

Закройте и снова откройте PowerShell. Затем:

```powershell
git clone https://github.com/UTALIPOV250618/mojo_studio.git
cd mojo_studio
git checkout feat/phase2-import-analysis
py -3.12 -m venv .venv
.venv\Scripts\pip install -e ".[dev]"
```

Если проект уже скачан: `git fetch; git checkout feat/phase2-import-analysis; git pull; .venv\Scripts\pip install -e ".[dev]"`.

## 2. Автотесты

```powershell
.venv\Scripts\python -m pytest -q
```

Ожидается около 441 пройденного теста. Если что-то упало — сохраните вывод целиком.

## 3. Запуск программы

Отдельная тестовая папка, чтобы не смешивать с настоящими проектами:

```powershell
$env:TOYSTUDIO_HOME = "$env:USERPROFILE\Той Студия тест"
.venv\Scripts\python -m toystudio.app.main
```

Для проверки подойдут 2–3 любых видео с телефона или камеры по 1–5 минут; лучше, если одно лежит в папке с русским названием и пробелами.

## 4. Что проверить

Отмечайте ✅ или ❌ и записывайте, что пошло не так.

**Экран «Проекты»**
- [ ] При первом запуске — «Смонтируем первый той» и кнопка «Новый проект».
- [ ] Папка с видео, перетащенная на окно, открывает создание проекта с этими файлами.

**Создание проекта**
- [ ] Название, дата и тип тоя задаются; дата подставляется из видео.
- [ ] Видео перетаскиваются или выбираются кнопкой; у каждого — «Проверяем…», потом «Готово ✓».
- [ ] Строка «На диске …: свободно …, нужно ~…» показывается.
- [ ] Один и тот же файл, добавленный второй раз, — «Уже добавлен».
- [ ] С включённым «Копировать файлы в папку проекта» файлы копируются (видно «Копируем… N%»).
- [ ] Обрезанный или повреждённый файл — баннер «Файл … не читается» с «Продолжить без него» / «Заменить файл».
- [ ] «Начать анализ» активна, только когда есть хотя бы одно проверенное видео.

**Анализ**
- [ ] Пять этапов, общий прогресс и «ещё ~N мин».
- [ ] Этапы завершаются с подписями («Найдено N смен сцен», «Чётко: …»).
- [ ] «Остановить» → «Продолжить анализ» и «Пройденные этапы сохранены»; продолжение не начинает заново готовые этапы.
- [ ] Закрытие окна во время анализа спрашивает «Свернуть» / «Остановить и закрыть».
- [ ] После «Остановить и закрыть» и нового запуска карточка ведёт на экран анализа, анализ продолжается и завершается.
- [ ] После остановки в диспетчере задач нет оставшихся `ffmpeg.exe` и лишних `python.exe`.
- [ ] «Свернуть» → значок в трее виден, клик возвращает окно, правый клик — «Открыть» / «Выйти».
- [ ] На значке программы в панели задач идёт прогресс.
- [ ] По окончании приходит уведомление «Анализ «…» готов».
- [ ] Отключённый во время анализа диск с видео → файл показан как «Файл не найден…», уведомления о готовности нет.

**Моменты**
- [ ] Ещё во время анализа справа появляется «Уже найдено», карточки добавляются по одной, новые сверху.
- [ ] На карточке: тип (Тост, Танец, Аплодисменты…), время начала и длительность, причина одной строкой, метка качества, кадр-превью.
- [ ] Этап 2 завершается подписью про участки речи, этап 5 — «Найдено N моментов».
- [ ] Видео без звука: этап 2 пропущен, моментов нет, анализ всё равно завершается.
- [ ] Уведомление по окончании называет число моментов («найдено N моментов»); клик по нему открывает анализ.
- [ ] Закрыть проект и открыть заново с экрана «Проекты»: лента показывает те же моменты, а при длинной ленте внизу есть «и ещё N».

**Внешний вид и язык**
- [ ] Окно 1280×720 и масштаб Windows 125 %: тексты не обрезаны, кнопки не налезают.
- [ ] Переключатель «Кыргызча» меняет тексты сразу; тексты не обрезаны (перевод черновой).
- [ ] Во время анализа и при смене языка не мелькают чёрные окна консоли.

**Скорость (по желанию)**
- [ ] Запишите длительность видео и время анализа: для 1080p 25/30 к/с ожидается около 8× реального времени (10 мин видео ≈ 1,3 мин), для 1080p 50/60 — около 4×.

## 5. Как сообщить о проблеме

Пришлите номер пункта, что сделали, что ожидали, что получилось, и снимок экрана. Если программа упала — текст из окна PowerShell.

Данные теста лежат в `%USERPROFILE%\Той Студия тест`; эту папку можно удалить после проверки.
