# Спайки фазы 0 («Той Студия»)

Короткие исследовательские скрипты, которые отвечают на риски R1–R4 из `docs/architecture.md`.
Пакет `toystudio` от них не зависит и не импортирует `spikes/`.

## Приватность (обязательно)

- Реальные записи тоев лежат **только** в `spikes/data/`. Эта папка в `.gitignore`: ни один файл оттуда не должен попасть в git.
- Реальные записи не загружаются в сеть: ни в облачные хранилища, ни в API моделей.
- В облачную модель (S4) уходит только текст (расшифровка и описание событий), никогда видео или аудио.
- В репозиторий идут только синтетические файлы из генератора и JSON с цифрами из `spikes/results/`.
- Перед коммитом: `git status` — в списке не должно быть `spikes/data/`.

## Установка

```
python -m venv .venv
.venv/bin/pip install -e ".[dev,spikes]"      # Windows: .venv\Scripts\pip
```

Нужны `ffmpeg` и `ffprobe` версии 5.1 или новее (флаг `-fps_mode`) в `PATH`. Все скрипты принимают пути аргументами и работают с кириллицей и пробелами.

## Где лежат данные

```
spikes/data/<той>/
    камера1/IMG_0412.MP4
    камера2/...
    refs/<той>.csv        # эталонная расшифровка: file,start,end,lang,text
    markup/<той>.csv      # разметка монтажёра: file,start,end,type
```

`<той>` — короткое имя без персональных данных, например `toy-01`.
Синтетический набор (3 клипа по 60 с и трек 120 с) делается командой:

```
python -c "from pathlib import Path; from spikes.common.media import generate_set; print(generate_set(Path('spikes/data/synthetic')))"
```

## Результаты

JSON с замерами пишет `spikes.common.results.write_result(spike, name, data)` в
`spikes/results/<спайк>/<имя>-<UTC-время>.json`. К данным добавляются `machine`
(ОС, CPU, RAM, GPU), `ffmpeg_version` и `git_rev`. Эти файлы коммитятся.
Цифры производительности считаются только с эталонного Windows-ПК; цифры с Mac помечаются «Mac, не для решения».
Время во всех результатах — целые микросекунды.
